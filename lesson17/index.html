Почнімо

За правильну першу перевірку — 100% балів завдання, другу — 90%, наступні — 80%. За нерозв’язані завдання зараховуються правильні частини. Змінюй фрагменти вільно: спроба починається лише кнопкою «Перевірити».

Як опрацьовувати списки

Коротко пригадай пошук зі списком, а потім розглянь функції та методи. У прикладах списки числові.

1. Повторення з уроку 16

Індекси починаються з нуля. a[-1] бере останній елемент, а a[::-1] створює перевернуту копію. Якщо вона збігається з a, список є паліндромом. Його також можна перевірити, порівнюючи симетричні пари.

t in a перевіряє наявність значення. Для пошуку елемента, більшого за поріг, переглядай елементи по черзі. break зупиняє цикл після знахідки. Гілка else циклу for виконується, якщо цикл завершився без break.

a = [3, 5, 3]
print(a == a[::-1])  # True
print(5 in a)        # True

2. Функції для числових списків

len(a) дає кількість елементів, sum(a) — суму, min(a) і max(a) — найменше та найбільше значення. Для пошуку крайніх значень потрібен непорожній список.

a = [2, 4, 6, 8, 4]
print(len(a), sum(a))  # 5 24
print(min(a), max(a))  # 2 8

У власній функції суму починають з нуля. Для пошуку мінімуму й максимуму можна почати з першого елемента й оновлювати обидва значення в одному циклі.

3. Методи списку

Метод викликають через крапку. append додає в кінець, insert уставляє за індексом, remove видаляє перший збіг за значенням. pop видаляє і повертає елемент за індексом, без аргументу — останній. clear очищає весь список.

a = [2, 4, 6, 4]
a.remove(4)     # [2, 6, 4]
x = a.pop()     # x = 4, a = [2, 6]

count повертає кількість збігів, а index — індекс першого збігу. Перед index перевір наявність значення, інакше можливий ValueError.

4. Від операцій до задач

Щоб знайти найвищу оцінку та кількість її входжень, спочатку обчисли максимум, а тоді порахуй його повтори. Два значення можна повернути однією командою return і прийняти у дві змінні.

def summary(a):
    top = max(a)
    return top, a.count(top)

mark, count = summary([9, 12, 8, 12])

Середнє дорівнює сумі, поділеній на кількість. Для підрахунку оцінок нижче від середньої збільшуй лічильник лише для значень, менших від нього.
